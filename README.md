# 🛡️ Zexy Admin Dashboard

## 📌 Project Overview
The `zexy_admin_web_app` acts as the fortified global oversight deck providing administrators ultimate control over the network. It handles financial compliance bounds, content moderation pipelines, creator payouts, and expansive analytic tracking.

**Target User**: Platform Administrators

## 🛠 Tech Stack
- **Framework**: Next.js
- **UI Components**: Shadcn UI / Material UI
- **Data Tables**: TanStack Table
- **Charts**: Recharts / Chart.js

## ✨ Key Features
- **Macro Analytics**: Renders holistic financial health flows aggregating native tipping, subscription, and product metrics dynamically.
- **User Moderation**: Granular toggle states terminating Creator APIs instantaneously or blocking aggressive Fan tunnels globally.
- **Payout Management**: Explicit ledgers checking verified banking limits natively executing transaction webhooks strictly.
- **System Traceability**: Live metric tracking defining active WebRTC room congestion bounds effectively.

## 🏗 Architecture Role
- **FastAPI**: Bypasses conventional creator/fan controllers directly dialing isolated admin endpoints verifying deep database conditions organically.
- **Node.js**: Optionally reads total active socket arrays checking load-balancer health explicitly.

1. **Install**: `npm install`
2. **ENV config**: Direct securely to local/production backend environments.
3. **Run**: `npm run dev`
